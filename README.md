# ShopEase – E-Commerce Web Application

## 🌐 Live Website

**Visit ShopEase:** https://shopease-ecommerce-usrn.onrender.com

ShopEase is a full-stack e-commerce web application where users can browse products, register, log in, add products to their cart, and place orders.

## 🚀 Features

- User Registration and Login
- User Authentication
- Product Listing
- Add Products to Cart
- Remove Products from Cart
- Checkout
- Order Creation
- Order History
- Automatic Stock Updates
- Product Images

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI

### Database
- PostgreSQL
- Neon Database
- SQLAlchemy ORM

### Deployment
- Render

## ⚙️ How to Use

1. Open the live website.
2. Register a new account.
3. Log in to your account.
4. Browse the available products.
5. Add products to your cart.
6. Proceed to checkout.
7. View your order history.

## 🌍 Deployment

The application is deployed using Render, with Neon PostgreSQL as its database.
